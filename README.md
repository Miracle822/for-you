# For You

A birthday site for your wife: her song, her photos, hosted free on GitHub Pages (no domain to buy).

## 1. Add your files

1. Put the song in `audio/` and name it `song.mp3` (or change `songFile` in `config.js`).
2. Put photos in `photos/` (`.jpg`, `.png`, or `.webp`).
3. Open `config.js` and fill in her name, your name, the message, and each photo path:

```js
photos: [
  "photos/us-1.jpg",
  "photos/us-2.jpg",
],
```

## 2. Try it on your computer

Open `index.html` in a browser. Chrome or Edge is fine.

## 3. Put it on GitHub (free)

GitHub Pages gives you a link like:

`https://YOUR-USERNAME.github.io/for-you/`

That is a real website. You do not buy a domain.

### Easiest way if Git is not installed

1. Go to [github.com](https://github.com) and create a free account.
2. Click **New repository**, name it `for-you`, keep it **Public**, create it.
3. On the new repo page, click **uploading an existing file**.
4. Drag every file and folder from this project into the page (including `index.html`, `config.js`, `audio`, `photos`).
5. Click **Commit changes**.
6. Open **Settings → Pages**.
7. Under **Branch**, choose `main` (or `master`) and `/ (root)`, then Save.
8. Wait a minute. GitHub will show the site URL at the top of that Pages settings screen.

If GitHub asks you to use Actions, choose **Deploy from a branch** instead.

## Keep it private from strangers

GitHub Pages on a free account is **public**. Anyone with the link can open it.

Do not post the link on social media if the photos are private. Send her the link in a message instead.

If you later want the page private, GitHub requires a paid plan, or you can unpublish it from Settings → Pages.
